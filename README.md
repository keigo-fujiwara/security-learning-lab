# セキュリティ対策ラボ

日本を狙うサイバー攻撃から身を守るための、手を動かして学ぶセキュリティ対策演習サイトです。
攻撃者の手口（攻撃側の視点）を理解し、それを見抜き・防ぐ（防御側の視点）スキルを、コードやコマンドを操作しながら身につけます。

| LAB | 内容 |
| --- | --- |
| 01 フィッシング見破り | URL解析ツール、偽SMS・メールの判定 |
| 02 パスワードとハッシュ | 強度チェッカー、Web Crypto による SHA-256 / PBKDF2 比較 |
| 03 セキュアコーディング | XSS・SQLインジェクション・IDOR のコード修正と自動テスト |
| 04 ログ分析 | 模擬ターミナル（grep/awk/sort/uniq）で不正アクセス調査、IPブロック |
| 05 セキュリティヘッダー | CSP評価器、HSTS・Cookie属性の設定 |
| 06 メール認証 | SPF/DKIM/DMARC ヘッダー判定、模擬 dig、DMARC 設定 |
| 07 日本を狙う脅威 | ランサムウェア等の解説、対応シナリオ、対策チェックリスト |

すべての演習はブラウザ内の模擬環境で完結し、外部への通信は行いません。
HTML / CSS / JavaScript のみで構成され、GitHub Pages でそのまま公開できます。
